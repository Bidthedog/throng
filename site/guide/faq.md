# FAQ

Short answers, each linking to the task that settles it.

## Does throng update itself?

No. Install a new release the way you installed throng; on Linux, the package repository brings updates with
your system's own updates. See [Install throng](quick-start.md#install-throng).

## Are my files deleted when I remove a project?

No. See [Remove a project](projects.md#remove-a-project).

## Do terminals keep running when I close throng?

Yes, unless you choose to end them. See
[Keep terminals running after you close throng](terminals.md#keep-terminals-running-after-you-close-throng).

## Where are my settings?

In plain files. See [Edit config files by hand](preferences.md#edit-config-files-by-hand).

## Can I run several copies of throng?

No; one throng runs at a time. Use [sub-workspaces](sub-workspaces.md) for more windows.

## What is a sub-workspace?

Another window of the same project. See [More windows: sub-workspaces](sub-workspaces.md).

## Why does Ctrl+C not copy in a terminal?

Because it interrupts the running program. See [Copy, paste and drop paths](terminals.md#copy-paste-and-drop-paths).
