# Implementation Plan: Editor Language Coverage — Filename Detection and New Languages

**Branch**: `feature/S055-I70-editor-language-coverage` | **Date**: 2026-10-14 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/055-editor-language-coverage/spec.md`

## Summary

Add a **filename rung** to 016's language detection — exact names, single-wildcard patterns and
folder-qualified names — ranked between a document's manual override and the user's extension mapping,
and grow the registry from 31 to 55 languages. Twenty-one grammars already ship in
`@codemirror/legacy-modes`; Batch, Dotenv and Ignore file get small hand-written stream grammars. The
change is pure data plus one new rung in core, one line per grammar in the renderer, three new tag
mappings in the highlight style, and documentation.

**Scale/Scope**: 24 new descriptors, 7 extended descriptors, ~45 filename entries, 3 hand-written

## Iteration 2026-10-14: resetting an override (US6, FR-024–FR-024c)

- **Clearing** is `DocumentClient.setState(projectId, relPath, null)`, which already exists; no IPC, daemon or
  schema change.
- **Re-resolution** reuses `use-editor.ts`'s `refreshLanguage`, which reads the stored override, runs the
  FR-007 chain and re-derives the indentation (016 FR-010b), so a reset needs no detection code of its own.
- **Every view** (FR-024a, 016 FR-028b): nothing told an already-open panel that another panel had changed the
  document's override. A window-local event, `editor/document-language-events.ts`, is published after the
  stored value is written; each editor whose project and relative path match re-runs `refreshLanguage`. Setting
  publishes to the other panels, because the acting panel has already applied its choice. Resetting publishes to
  all of them, the acting panel included. A sub-workspace window is a separate renderer realm and picks the
  change up on its next refresh. That is a known limit, recorded in the report.
- **Surfaces**: an `IconButton` (`destroy` token) after the language button in the strip's measured controls
  group (`status-strip.tsx`), and a *Reset Language* item after *Set Language…* in `content-menu.ts`, disabled
  unless the panel's resolution source is `override`.
- **Tests**: unit tests for the event's document matching and the menu item, and a component test for the strip
  control: shown only for an override, and pressing it clears the stored value with `null`.
