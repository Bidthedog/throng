# Tasks: macOS Support

**Input**: Design documents from `specs/070-macos-support/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md

**Tests**: Required. Principle V is test-first, and FR-012, FR-036 and FR-050 make the suites deliverables. Within each
task the failing test comes first.

**Test layers**: `unit`, `unit-isolated`, `component`, `integration`, `contract` (vitest projects) and E2E (Playwright).
Local runs follow `running-tests` and `throng-testing`: only the files under the cursor. **There is no Mac**: a test that
needs macOS is written here, runs on Linux as far as it can (pure logic under `withHostTraits(macos)`), and is proved on
the hosted macOS runners by the CI jobs from Phase 2. A macOS-only contract or integration test carries
`skipUnlessMacos` with its reason.
