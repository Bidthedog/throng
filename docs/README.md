# throng docs

Every guide, one line each. Each topic has one home; the others link to it.

**Learning throng?** Read the [user guide](../site/guide/index.md), published at
[throng-ide.com/guide](https://throng-ide.com/guide/) and opened in throng with **F1**: how to do each thing, task by
task, starting with the [Quick start](../site/guide/quick-start.md). The pages below are the reference it links to: every
setting, every binding, every install step.
